## 1. Collector and journal

First read the [main reconciliation](../../plans/arena-application-integration/main-reconciliation.md) and current provider/evidence documents; extend existing sources instead of repeating already delivered qualification work.

- [x] 1.1 Define namespace/round/mapping/policy-bound observation schema, exact inputs, nullable source times and evidence identities using shared read DTOs. `agent/src/observations/schema.ts` (`market-observation-v1`): full namespace, battle/round/community, frozen policy hash and mapping version, source asset and optional reference, source name/kind/pool/quote, scaled integer inputs, evidence hash, nullable provider time and separate acquisition time. The fixture/recorded/live kind is part of each sample. Rolling 24h volume and FDV have no field and are rejected by name.
- [x] 1.2 Implement explicitly configured chain/reference aliases with chain-aware address normalization; reject ambiguous/default mappings. Scope delivered: the collector takes asset and reference identity only from the frozen round (contract view plus the protocol registry), normalizes 20-byte EVM addresses per chain id and refuses anything else; there is no ticker lookup and no default reader. Provider-specific alias tables are not built because no live provider is qualified (see 1.4).
- [x] 1.3 Implement durable append-before-publication journal, atomic manifest, deduplication, replay and explicit corruption/capacity handling without adding a database migration. `agent/src/observations/journal.ts`: hash-chained append-only `journal.jsonl` (fsync before acknowledgement), atomic `manifest.json`, single-writer lock that is never stolen, idempotent late retries, conflict/capacity errors that degrade health, torn-tail discard, corruption that refuses to open, retraction records with a revision counter. No database.
- [ ] 1.4 Integrate collector ingestion with frozen intervals and qualification outputs; retain missing boundaries, gaps and unsupported mode reasons. Partly delivered: `ObservationCollector` enforces the recorded window, the qualified-mode gate and unsupported-mode reasons, and a source outage is a gap. Still open: the process that runs the collector against a provider on a schedule (the lifecycle oracle from #147 only READS persisted evidence and does not sample providers), and the live provider adapter stays disabled (`liveSourceUnavailable`) until provider qualification exists.

## 2. Read and chart delivery

- [x] 2.1 Extend read service/gateway with bounded round/community/time queries, cursors, revisions, watermarks and coverage metadata. `GET battles/{id}/observations` in the application read service and the web gateway (`OBSERVATION_JOURNAL_DIR`, `ARENA_APPLICATION_OBSERVATION_SCOPE`), page limit 1 to 50, cursor `after`, `revision`, `retractedSinceCursor`, watermark and coverage. A missing or corrupt journal is a 503.
- [x] 2.2 Implement provisional rational score projections only for qualified inputs; keep contract outcome references separate and gate unsupported modes. Exact BigInt rationals for price gain and maximum drawdown only, `authoritative: false`, recorded round/winner in a separate field. Market-cap and volume modes cannot be qualified (`OBSERVATION_QUALIFIED_MODES` rejects them) and stay unavailable.
- [x] 2.3 Connect existing charts through protocol-specific adapters, including legacy snapshot/spot-versus-TWAP labels and explicit fixture isolation. `observation-series.ts` adapts lifecycle evidence for the existing `ScoreChart` and is shown from the application battle list for locked and decided battles; the legacy snapshot adapter and the labeled scripted demo are unchanged, and an unavailable backend shows a message, never demo samples.
- [x] 2.4 Add cancellable delta polling and revision reconciliation; preserve gaps and separate source cadence from display refresh and paused visuals. `createObservationPoller`: bounded snapshot, deltas after the watermark, reload on a revision change, superseded/cancelled/foreign responses ignored, stale flag on a failed refresh, hidden tab pauses only display refreshes.
