Valtrums uses a few terms that have a specific meaning in the app and these docs. Use this list when a word on a battle page isn't clear.

| Term | Meaning |
| --- | --- |
| **Battle** (arena) | One contest between two or more token communities, with one scoring mode and a start time |
| **Creator** | The account that opened the battle. Earns 0.05% of every losing deposit by default. |
| **Community** (crew) | Everyone backing the same token in a battle. The app labels them Crew 01, Crew 02 and so on. |
| **Allowlist** | The tokens allowed to join battles: CASHCAT, WALLET, GOOD, VLAD and DEGEN |
| **Position** | Your registered place in a community, and the amount credited to it |
| **Deposit** | Tokens you send to back a community. Your share of any prize depends on its size. |
| **In escrow** (deposit) | A deposit waiting for its community's safety and backing approvals |
| **Approval** | The safety check and backing check a community needs before its deposits count |
| **Start time** | When joining and deposits close and the battle tries to lock |
| **Lock** | The moment the communities, deposits and settings are frozen |
| **Round** | A 30-second scoring period |
| **Scoring mode** | The rule that decides who wins a round. See [Scoring modes](/concepts/scoring-modes). |
| **Overtime** | Extra rounds played only by tied leaders, with no limit |
| **Settlement** | Splitting each losing deposit among the winners, the creator and the protocol |
| **Entitlement** | A recorded reward that belongs to you but hasn't been claimed or paid yet |
| **Winning principal** | The winning community's own deposits, held for the winners' vote |
| **Winners' vote** (DAO decision) | The vote on how much winning principal to burn and how much to return |
| **Sent to sink** | Burned tokens, sent to an unrecoverable address on Robinhood Chain |
| **Backed token** | A token on NEAR that stands for one token held in custody on Robinhood Chain |
| **Custody** | Where the original tokens are held on Robinhood Chain |
| **Payout** | Redeeming a reward as the original token on Robinhood Chain |
| **Player agent** | An AI-driven account that plays for you with funds you give it |
| **Faucet** | The page where you claim free test tokens |
