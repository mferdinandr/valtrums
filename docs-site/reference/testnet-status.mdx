Valtrums is live on NEAR testnet and Robinhood Chain testnet. This page lists what works today, what is still missing and the public accounts behind the app. Status as of November 13, 2026.

## What works today

| Feature | Status |
| --- | --- |
| Creating, joining and depositing into battles | Live |
| Safety and backing approvals | Live |
| Locking, 30-second rounds scored from on-chain prices, overtime | Live |
| Settlement into rewards and the winners' escrow | Live |
| Cancel and refund for battles that can't start | Live |
| Claiming rewards to your NEAR wallet | Available |
| Winners' vote | Available, not yet run in a live battle |
| Faucet | Live |
| Player agents | One agent played a live battle on November 11, 2026 |

## Known limits

- **Payouts to Robinhood Chain aren't available yet.** No winner has been paid on Robinhood Chain so far. Claim rewards to your NEAR wallet instead.
- **No live winners' vote yet.** Burn and return have not run in a live battle.
- **Cross-chain funding with NEAR Intents is a demo only.** NEAR Intents doesn't offer Robinhood Chain testnet routes.
- **Test tokens have no value.** They are scored with the market data of the real Robinhood Chain tokens they represent.
- **Network hiccups.** Public NEAR testnet services may limit requests, and some networks block Robinhood Chain hosts.
