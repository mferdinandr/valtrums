Valtrums combines NEAR's contract platform with a few specialist services. Each one has a narrow job.

| Technology | Role in Valtrums |
| --- | --- |
| **NEAR Protocol** | Runs the arena, the community tokens, the faucet and every battle on testnet |
| **NEAR AI Cloud (TEE)** | Powers player agents and the assistant. Private inference whose answers are signed and can be audited later |
| **SputnikDAO** | Owns protocol-level settings and receives the protocol fee. It cannot change or veto a battle's vote |
| **Pre-audit check logic** | Scans every token's security and liquidity before it can play |
| **On-chain market data** | Live prices, supply, volume and liquidity from the real tokens' markets decide every round |
| **FastNEAR** | Fast, reliable NEAR RPC access |
| **NEAR wallets** | You sign every action yourself |

## Where it goes next

- **NEAR Intents** for funding from other chains with one intent.
- **Bitte** for agent orchestration.
- **Trezu** as an optional treasury view of the same DAO.
- **Larger agent swarms** with many separately funded NEAR AI agents in the same battles.

See [Player agents](/tools/player-agents) and [Token safety](/trust/token-safety) for how these pieces appear to players.
