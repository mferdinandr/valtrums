Valtrums is live on NEAR testnet. This page lists what works today and the public accounts behind the app. Status as of November 13, 2026.

## What works today

| Feature | Status |
| --- | --- |
| Creating, joining and depositing into battles | Live |
| Safety and backing approvals | Live |
| Locking, 30-second rounds scored from on-chain prices, overtime | Live |
| Settlement into rewards and the winners' escrow | Live |
| Cancel and refund for battles that can't start | Live |
| Claiming rewards to your NEAR wallet | Available |
| Winners' vote | Live |
| Faucet | Live |
| Player agents | One agent played a live battle on November 11, 2026 |

## Good to know

- **Test tokens have no value.** They are scored with the live on-chain market data of the real tokens they represent.
- **Busy network?** If a page is slow or a transaction fails, wait a moment and try again.
